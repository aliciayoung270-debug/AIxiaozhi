# 小织定时任务原型

入口：`prototype.html`，也可从项目共享侧边栏的「定时任务」进入。

来源：Notion「定时任务」 https://app.notion.com/p/40168e9844668087ab36c05ea310f235 ；项目 DESIGN_SYSTEM.md；客户定制/飞阅定制/prototype.html 的报告布局参考；用户提供的 2026-10-19 飞阅预警汇总。

## 已实现

- 任务配置与执行历史两个视图，搜索和状态筛选；任务列表移除状态列。
- 统计卡片展示「今日已执行任务数」：按北京时间自然日、任务 ID 去重，包含执行成功与执行失败的任务。
- 创建按钮下拉选择手动创建或通过对话创建；后者进入首页独立会话并默认引用「定时任务创建」Skill。支持编辑、暂停和启用。
- 每天、每周、每月的整点计划，北京时间，下次执行预览。
- 可选到期日期，机器人连接前置校验，钉钉/企业微信，自己/同事/群聊配置。
- 模拟执行生成独立会话，保留提示词快照；历史展示具体执行时间、耗时、成功或失败，消息推送统一展示「不需要推送」「已推送」（失败未生成报告时不需要推送）。
- 「查看会话」在新窗口（或由浏览器决定的新标签页）打开独立 session 页面，支持继续对话、刷新、查看报告与返回执行历史；不存在或过期的会话展示提示。
- 执行历史以对话 Session 展示，不设面包屑；顶部说明定时任务来源、任务名称、执行时间、耗时与执行结果，底部保留对话输入框。
- 执行会话支持继续提问、Enter 发送、Shift + Enter 换行和中文输入法；消息按执行记录持久化，打开报告再返回保留对话和输入草稿。回复为标明来源的本地演示，不调用真实 Agent。
- 共享 sidebar.js 和 shared.css，主导航增加「定时任务」；最近对话统一展示执行会话的任务名称、时间与「定时」角标，点击直接进入对应 Session。

## 约定与限制

- 本地交互原型，无真实调度、Agent、联系人、机器人或消息发送；配置存储在当前浏览器 localStorage 中。
- 独立会话在当前浏览器保留消息、Skill 引用和配置草稿，并出现在共享侧边栏的最近对话。Skill 行为采用本地规则演示，缺失信息在会话中追问，齐全后可核对配置并创建。
- 月度日期在当月不存在时跳过该月；到期日在北京时间当天结束后停止。
- 执行历史按北京时间向前推 3 个自然月保留，截止时间精确到分钟；目标月无对应日期时取月末。页面加载、列表刷新时清理过期记录及其会话数据，并同步本地存储。
- 唯一成功的业务报告示例数据截止 2026-10-19，并非今日实时数据。没有商品级明细，因此未虚构 ASIN 排名或热力图。
- 原始飞阅 HTML 单独作为样式参考链接，其原始数据不与本次历史快照混用。
