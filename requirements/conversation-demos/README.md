# 对话演示场景库

入口：prototype.html，也可从首页「演示场景库」进入。不切换租户；客户名只是场景名称。飞阅固定为2026-10-22截止快照；扬腾直接引用用户已有2026-07-02—07-15报告，FM为演示映射，禁止现场随日期滚动。

## 文件职责

- scenarios.js：每个场景的稳定ID、触发提示词、上下文、模拟进度、总结、追问及回复。增加普通问答只需在followups追加q、match（正则）、a。
- session.js：接入根目录现有对话页；负责启动、步骤、报告预览、追问匹配及模拟执行状态。通用确认逻辑只作用于当前会话。
- 扬腾原报告：reports/扬腾品线分析报告.html；只引用，未修改。不再保留重复生成的简化版。
- reports/feiyue-acos.md：飞阅Markdown原始报告；同名HTML是便于阅读的预览副本，改报告时两者一起更新。
- demo.css：业务布局，引用shared.css变量，不复制侧边栏。

新增场景：追加scenarios.js记录、准备reports/{id}.html，若format为MD再提供{id}.md；维护首页触发匹配规则（session.js的send），或直接通过场景库进入。所有对话及报告数值需同步，不得只改一边。

## 演示路径

1. 扬腾：触发→14日报告与总结→本周三件事→为何不全部暂停尾部→如何复核。
2. 飞阅：触发（父ASIN预警上下文预置）→按1→2→6→3→4→7→5→8链路生成MD→归因证据→执行方案→确认模拟执行→复核→确认模拟回滚。
3. 未覆盖输入显示可选追问，不假装已接入真实LLM。重新演示/返回首页会清除模拟执行状态，不会重复调用任何接口。刷新深链接重开场景。
