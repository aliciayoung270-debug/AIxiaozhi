# 父ASIN近30天ACOS突然升高分析报告

Mock 演示数据｜父ASIN B0F1DEMO01｜US / 飞阅演示店 / FY-US-01｜便携投影仪｜B类利润款。

对象由当前演示预警带入；没有切换租户。预警线35%为本场景假设。分析仅覆盖SP及期间有花费的已暂停活动。

本期：2026-09-23—2026-10-22；上期：2026-08-24—2026-09-22，各30个站点完整日。固定快照假设归因完整、60日历史可用。原方法论注明当前L2仅支持31天：真实接入时若仍受此限制，不能声称已完成前后30天比较。

## 结论性质：需要干预

最近突然升高，未满足“一直偏高”。主要排查方向是CPC上升，其次是CVR下降。问题集中于两个SP活动，调价日志与恶化时点相邻，但尚不能认定唯一根因。方向判断置信度中等，干预采用小步可回滚方案。

## 分析链路

按方法论顺序：1预警定性 → 2恒等式拆解 → 6商品健康 → 3结构与花费 → 4问题缩圈 → 7市场竞争 → 5变化事件 → 8策略性投入 → 建议约束。

## 2. 恒等式拆解

ACOS = CPC ÷ (CVR × 客单价)。

| 因子 | 上期 | 本期 | 变化 |
| --- | --- | --- | --- |
| CPC | $1.00 | $1.40 | +40% |
| CVR | 10% | 8% | -2个百分点 |
| 广告客单价 | $50 | $50 | 持平 |

本场景对数分摊：CPC解释约60.1%、CVR解释约39.9%的ACOS对数变化，客单价贡献0%；不代表因果占比。计算：ln(1.4)/ln(1.75) 与 ln(1.25)/ln(1.75)。总变化为20%→35%，增加15个百分点。

4. 当前B类、FBA可用900件、近7天可售45天，暂无断货约束；不触发D/E类调价规则，也不因为ACOS高建议提价。
